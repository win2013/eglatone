A personal and professional profile theme for technologists, inventors,
investors and expert witnesses.



== Description ==

Eglatone is a derivative work of Abletone by Catch Themes, reworked around a
personal-profile homepage rather than a music site.

What this fork adds:

* Achievements hero - headline statistics, highlight pills, an introduction
  with a "Read more" fold, a CV button and a call to action that opens a
  built-in contact form (honeypot, timing check, nonce and rate limiting).
* Press mentions strip - a scrolling row of publication logos, each in a
  uniform box, greyscale with colour on hover.
* News ticker - a seamless marquee driven by any RSS or Atom feed, cached in
  a transient, with a live feed-status readout in the Customizer.
* Blog grid - 2, 3 or 4 columns with a "... more" button that loads the next
  batch by AJAX instead of paginating.
* Section carousels - Services and Featured Content render as N-up carousels
  with the column count set in the Customizer.
* Single post media band - featured image framed on a full-bleed band with
  the audio player pulled up beneath it, plus category chips, an author
  byline and reading or listening time.
* Schema (JSON-LD) editor - Settings > Schema (JSON-LD), validated on save,
  keeping the last valid document live if a bad edit is submitted.

All of the above are configurable under Appearance > Customize > Theme
Options. No section is required; each can be switched off.

== Installation ==

1. Appearance > Themes > Add New > Upload Theme, choose the zip, Install Now.
2. Activate.
3. Appearance > Customize > Theme Options to configure the sections.

If you are migrating from Abletone, run the included migration first so your
existing Customizer settings carry across. See MIGRATING-FROM-ABLETONE.md.
